Server SDK reference docs

API reference for the ten SignalWire server SDKs, each built with the standard doc tool for its language. Pick a language below, or use the dropdown in the navbar.

About this demo

None of these doc sites are custom. Rust developers get rustdoc, Ruby developers get YARD, Java developers get Javadoc, all generated straight from the SDK source with nothing edited afterward. The idea is that reference docs should read the way docs in that language normally do, rather than forcing every SDK into one house style.

The navbar is a clone of the one on signalwire.com/docs, and the theme control in the top right switches each doc site between light and dark.
