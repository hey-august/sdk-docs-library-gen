SignalWire Server SDKs — language-native docs explorer

Ten SDKs. Ten canonical doc generators. One side-by-side preview. Each pane below is the unmodified HTML output of that language's standard documentation tool.

What you're looking at

Every language community has converged on a canonical generator for API docs — rustdoc for Rust, YARD for Ruby, godoc for Go, MkDocs for Python, and so on. The output of each one looks and behaves the way that community expects.

This POC stitches all ten together behind a single shell. Pick a language from the sidebar (or a card above) and the iframe loads that SDK's native docs — CSS, search, navigation, all preserved.

Generators per language Doxygen, DocFX, gomarkdoc, Javadoc, Pod::Simple::XHTML, Doxygen-PHP, MkDocs Material, YARD, rustdoc, TypeDoc
