About this demo

None of these doc sites are custom. Each one is generated straight from the SDK source by the canonical reference tool for its language, with nothing edited afterward. The idea is that reference docs should read the way docs in that language normally do, rather than forcing every SDK into one house style.

The navbar is a clone of the one on signalwire.com/docs, and the theme control in the top right switches each doc site between light and dark.

The language switcher in the navbar is just for the demo, to make it easy to flip between the ten outputs and compare them. A developer working in one language wouldn't need it; in production each SDK's docs would simply be linked from that SDK's page.
