Overview

Named, frozen view over the call-state vocabulary. Additive: the wire value stays a bare String everywhere (the events carry call_state as a String, Call#state is a String), and the flat CALL_STATE_* constants above remain the single source of the literals. This module wraps them with the Wave-A/Tier-1 idiom — a frozen ALL ordered list, a frozen TERMINAL set, and a terminal? predicate — so callers can ask CallState.terminal?(state) instead of hard-coding == "ended".

Grounded in signalwire/relay/constants.py (+CALL_STATES+) — the same closed, server-emitted lifecycle the Python reference enumerates. ended is the one terminal state (the call is gone; SignalWire::Relay::Call#wait_for_ended resolves on it).
