Optionalscheme

scheme?: "ws" | "wss"

WebSocket scheme — 'wss' (production, the default) or 'ws' (loopback fixtures and local audit harnesses). Reads from SIGNALWIRE_RELAY_SCHEME if not explicitly set; defaults to 'wss'.

Production deployments should never pass 'ws' — the value exists solely so the porting-sdk's audit_relay_handshake.py can drive the real client against a plain-WS loopback fixture without standing up TLS termination.
