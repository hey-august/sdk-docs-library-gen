    OptionalsigningKey

    signingKey?: string

    SignalWire Signing Key for verifying inbound webhook signatures. When set, AgentBase auto-mounts the webhook signature validation middleware on POST /, /swaig, and /post_prompt; unsigned or mis-signed requests are rejected with 403.

    Falls back to the SIGNALWIRE_SIGNING_KEY environment variable when omitted. When both are unset, signature validation is disabled and the agent emits a one-time warning on startup so operators notice.

    Per porting-sdk/webhooks.md: this MUST be treated as secret — never logged, never echoed to clients, never included in error messages.
