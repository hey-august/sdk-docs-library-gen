Class RelayEvent

Base class for all typed RELAY events.

Raw events arrive as signalwire.event JSON-RPC notifications; the client looks up the correct subclass in EVENT_CLASS_MAP and invokes RelayEvent.fromPayload to build a typed wrapper. Handlers receive this wrapper; they can always read the original dict from params.
