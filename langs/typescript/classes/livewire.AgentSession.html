    Class AgentSession<UserData>

    Mirrors a LiveKit AgentSession — binds an Agent to SignalWire.

    Call AgentSession.start with an Agent to construct an internal AgentBase and begin serving SWML. Pipeline-related options are accepted for API parity but are no-ops server-side.

    start

    • start(

      ): Promise<void>

      Start the session by binding the agent to a freshly-constructed AgentBase, mapping LiveKit-style options onto SignalWire AI params.

      Must be called before any other method on this session. The underlying AgentBase is not started here — use runApp or an AgentServer to serve it.
