Class ParameterSchema

Fluent builder producing a ParameterSchemaObject byte-identical to the equivalent hand-written parameters blob. Every method returns this for chaining; call build to obtain the plain object to hand to defineTool/defineTypedTool.

Insertion order is preserved: properties appear in the order their methods were called (matching a hand-written object literal), and required lists names in the order required received them.

    Add a string property constrained to a closed set of values, rendered as enum:[...] — the JSON-Schema form the model and the SignalWire validator both honour. This is the typed-closed-set affordance: pass one of the exported Tier-1 value arrays (RECORD_FORMATS etc.) or any literal list, and the values land verbatim in enum.

    Parameters

      Parameter name.

    • values: readonly unknown[]

      The allowed values (a readonly array — the as const Tier-1 arrays are accepted directly). Emitted as enum, in order.

    • description: string = ''

      LLM-facing description.

    • type: ParameterType = 'string'

      The JSON-Schema base type for the enum (default 'string').
