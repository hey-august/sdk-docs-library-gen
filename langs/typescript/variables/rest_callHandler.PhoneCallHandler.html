    PhoneCallHandler — enum of call_handler values accepted by PhoneNumbersResource.update.

    Named PhoneCallHandler (not CallHandler) to avoid colliding with the RELAY client's inbound-call-handler callback type already exported from src/relay/types.ts.

    Setting a phone number's call_handler + the handler-specific companion field routes inbound calls and auto-materializes the matching Fabric resource on the server. See the high-level helpers on PhoneNumbersResource (setSwmlWebhook, setCxmlWebhook, setCxmlApplication, setAiAgent, setCallFlow, setRelayApplication, setRelayTopic).

    Note: LAML_WEBHOOKS (wire value laml_webhooks) produces a cXML handler, not a generic webhook. For SWML, use RELAY_SCRIPT.

    Example

    import { PhoneCallHandler } from '@signalwire/sdk';

    await client.phoneNumbers.update(pnSid, {
      call_handler: PhoneCallHandler.RELAY_SCRIPT,
      call_relay_script_url: 'https://example.com/swml',
    });

    // Or use the typed helper:
    await client.phoneNumbers.setSwmlWebhook(pnSid, 'https://example.com/swml');
