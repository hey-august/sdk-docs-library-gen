Module error

Expand description

Typed error for the AgentServer surface and the shared HTTP(S) bind path.

Like RelayError, this replaces the old Result<_, String> returns on the server surface (register, serve_static, serve_static_files, and the internal bind_server) with a closed, inspectable failure set — matching the REST layer’s SignalWireRestError exemplar.

The data each failure carries lives in the variant (callers match rather than call getters), so the only public surface added is the type plus its Display / std::error::Error impls. #[non_exhaustive] leaves room to add new failure modes without a breaking change.
