Prompt Object Model (POM)

A typed tree of prompt sections that supports markdown / XML / JSON / YAML rendering. Direct port of signalwire.pom.pom from signalwire-python.

The two public types are PromptObjectModel (the root container) and Section (one node in the tree). Build a model with add_section / add_subsection, then render via render_markdown, render_xml, to_json, or to_yaml. All renderers match Python byte-for-byte — the cross-port parity contract lives in signalwire-python/tests/unit/pom/test_pom_render_parity.py.
