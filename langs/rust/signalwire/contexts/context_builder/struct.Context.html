pub fn add_step(&mut self, name: &str) -> &mut Step

Add a step to this context.

§Panics

Panics if a step with name already exists in this context, or if adding it would exceed MAX_STEPS_PER_CONTEXT. (The trailing .unwrap() cannot fail: it reads back the step just inserted.)

pub fn set_initial_step(&mut self, step_name: &str) -> &mut Self

Set which step the context starts on when entered.

By default, a context starts on its first step (index 0). Use this to skip a preamble step on re-entry via change_context.
