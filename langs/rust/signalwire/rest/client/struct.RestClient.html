Struct RestClient 

Source 
pub struct RestClient { /* private fields */ }
Expand description

Top-level SignalWire REST client.

Provides lazy access to every API namespace (fabric, calling, phone_numbers, datasphere, video, compat, etc.). Credentials can be supplied explicitly or pulled from environment variables.

Production HTTP transport is ureq (sync, blocking, real network I/O). Tests can substitute a stub via [with_http].
