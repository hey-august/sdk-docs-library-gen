Amazon Bedrock voice-to-voice agent.

BedrockAgent extends AgentBase (via composition + Deref) so it shares all of AgentBase’s features (prompt building, skills, tools, post-prompt, dynamic configuration) but emits an amazon_bedrock verb in the rendered SWML document instead of the standard ai verb.
