Typed builder for SWAIG tool-parameter JSON schemas.

AgentBase::define_tool / Service::define_tool take the function’s parameter schema as an untyped serde_json::Value — a properties object hand-written as nested json!({ ... }):

ⓘ
agent.define_tool(
    "search_faqs",
    "Search the FAQ knowledge base",
    json!({
        "query": {"type": "string", "description": "The question or keywords"},
    }),
    handler,
    false,
);

That is easy to typo ("strign", "desciption", a forgotten "type") and the compiler can’t help. ParamsBuilder is an additive, fully-typed convenience over the exact same wire output: it produces the identical properties object — so it drops straight into the existing, unchanged define_tool path. It is not a new format.

use signalwire::swaig::ParamsBuilder;
use serde_json::json;

let params = ParamsBuilder::new()
    .string("query", "The question or keywords to search")
    .build();

// Byte-identical to the hand-written form above:
assert_eq!(
    params,
    json!({"query": {"type": "string", "description": "The question or keywords to search"}})
);

§Two outputs, both byte-identical to the hand-written forms

  • build returns the properties object — what Rust’s define_tool(parameters) accepts (it wraps it as {"type":"object","properties": <this>}).
  • build_schema returns the full JSON schema {"type":"object","properties":{…},"required":[…]} — exactly the shape the Python reference’s _ensure_parameter_structure emits and the shape hand-written for register_swaig_function / DataMap full definitions. This is the form that carries a top-level required list.

§Closed-set (enum) properties

enum_of renders a schema "enum": [...] from any iterator of impl AsRef<str>, so the Tier-1 media enums plug straight in via their all() slices:

use signalwire::swaig::{ParamsBuilder, RecordFormat};
use serde_json::json;

let params = ParamsBuilder::new()
    .enum_of("fmt", RecordFormat::all(), "Recording container format")
    .build();

assert_eq!(
    params,
    json!({"fmt": {"type": "string", "enum": ["wav", "mp3", "mp4"], "description": "Recording container format"}})
);
