Struct FunctionResult 

Source 
pub struct FunctionResult { /* private fields */ }
Expand description

Result returned from a SWAIG function handler.

Serialises to {"response": "...", "action": [...], "post_process": true} where action is omitted when empty and post_process is omitted when false.
