import "github.com/signalwire/signalwire-go/pkg/livewire"

Package livewire provides a LiveKit-compatible API surface that runs on SignalWire's platform. Developers can use familiar LiveKit struct and function names — just change the import path to get SignalWire's infrastructure handling STT, TTS, VAD, LLM, and call control.

func (a *Agent) FunctionTool(name string, handler any, opts ...ToolOption) *Agent

FunctionTool registers a named tool on the agent. The handler must be

In the LiveKit-style case the function's string parameters are inferred and the return string is wrapped into a FunctionResult automatically.

func (*Agent) UpdateTools

func (a *Agent) UpdateTools(tools []any) *Agent

UpdateTools replaces the agent's tool list. Mirrors Python Agent.update_tools (livewire/init.py:394) which accepts List[Any] and stores self._tools = list(tools). In Go, the parameter is []any to keep the unexported toolDef out of the public signature (the original typed []toolDef made the method uncallable from external packages). Elements that aren't recognized tools are silently skipped, matching Python's permissive storage semantics. Returns the Agent for method chaining.
