SignalWire Go SDK godoc

Native Go SDK for SignalWire. Build voice, messaging, and AI-agent applications in Go using SWML, the Relay realtime protocol, and the SignalWire REST APIs.

This pane was generated from Go source comments using gomarkdoc, then styled to match the look of pkg.go.dev.

Install

go get github.com/signalwire/signalwire-go@latest

Quickstart

package main

import (
    "github.com/signalwire/signalwire-go/pkg/agent"
)

func main() {
    a := agent.NewAgentBase(
        agent.WithName("hello"),
        agent.WithRoute("/hello"),
    )
    a.PromptAddSection("Personality", "You are friendly.")
    a.PromptAddSection("Goal", "Greet the caller and find out what they need.")
    a.Run()
}
