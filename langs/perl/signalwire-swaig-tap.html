NAME

SignalWire::SWAIG::Tap - typed closed sets for FunctionResult->tap

SYNOPSIS

    use SignalWire::SWAIG::Tap qw(SPEAK HEAR BOTH PCMU PCMA);
    use SignalWire::SWAIG::FunctionResult;

    my $result = SignalWire::SWAIG::FunctionResult->new;

    # Named constants and bare wire strings are interchangeable:
    $result->tap( 'rtp://1.2.3.4:5000', direction => HEAR,   codec => PCMA );
    $result->tap( 'rtp://1.2.3.4:5000', direction => 'hear', codec => 'PCMA' );

    # Membership / iteration helpers:
    SignalWire::SWAIG::Tap->is_direction('hear');  # 1
    SignalWire::SWAIG::Tap->is_codec('OPUS');      # 0 (RELAY-only codec)
    @{ SignalWire::SWAIG::Tap->codecs };           # ('PCMU','PCMA')

DESCRIPTION

The two closed-set string parameters of SignalWire::SWAIG::FunctionResult's tap verb, surfaced as typed, named constants:

  • DIRECTION — which audio channel(s) to tap: speak, hear, or both.

  • CODEC — the RTP codec for the tapped media: PCMU or PCMA.

tap validates both inline and dies on anything outside the set; this module hoists those literal sets into a single source of truth so the accepted values are discoverable and autocompletable instead of living only inside the die strings. The constants are the canonical wire strings, so tap's signature is unchanged.

Distinct from RecordCall. The tap direction set is {speak, hear, both}: the inbound-listen channel is hear, not record_call's listen. Likewise this two-value codec set {PCMU, PCMA} is the SWAIG-tap codec set only — a strict subset of the RELAY connect/stream codec superset (PCMU, PCMA, OPUS, G722, ...). These vocabularies must never be conflated.

CONSTANTS

Exported on request via Exporter. The :directions tag pulls SPEAK/HEAR/BOTH; :codecs pulls PCMU/PCMA; :all pulls every constant.

    SPEAK => 'speak'    PCMU => 'PCMU'
    HEAR  => 'hear'     PCMA => 'PCMA'
    BOTH  => 'both'

METHODS

directions

    my $aref = SignalWire::SWAIG::Tap->directions;

Arrayref of the accepted tap-direction strings.

codecs

    my $aref = SignalWire::SWAIG::Tap->codecs;

Arrayref of the accepted tap-codec strings.

is_direction

    my $bool = SignalWire::SWAIG::Tap->is_direction($value);

True if $value is an accepted tap direction. Accepts the bareword constant too (it is just the string).

is_codec

    my $bool = SignalWire::SWAIG::Tap->is_codec($value);

True if $value is an accepted tap codec.
