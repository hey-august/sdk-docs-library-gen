Detailed Description

Iterates items across paginated API responses.

Mirrors Python signalwire.rest._pagination.PaginatedIterator: walks pages by following the links.next cursor and extracting query params from the URL.

Usage: foreach (new PaginatedIterator($http, '/api/path', ['k' => 'v']) as $item) { // ... }
