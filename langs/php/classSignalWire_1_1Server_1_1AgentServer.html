◆ serve()

SignalWire\Server\AgentServer::serve ( )

Start the server (blocking).

Mirrors Python's AgentServer SSL handling: when SWML_SSL_ENABLED is truthy and SWML_SSL_CERT_PATH / SWML_SSL_KEY_PATH point at a readable cert + key, the server is served over verified HTTPS via a Workerman SSL worker. Otherwise it falls back to PHP's built-in (plaintext HTTP) server.

◆ setupSipRouting()

SignalWire\Server\AgentServer::setupSipRouting ( string $route = '/sip',
bool $auto_map = true )

Set up central SIP-based routing for the server.

Mirrors Python's AgentServer.setup_sip_routing(route, auto_map). When called with no args, defaults match Python: route="/sip", auto_map=true.

Parameters
string$routePath for SIP routing (default "/sip"). Leading slash is added if missing; trailing slash is stripped.
bool$auto_mapIf true, existing agents have their SIP usernames auto-derived from their route.
