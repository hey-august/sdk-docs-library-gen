Detailed Description

Represents a RELAY messaging message (SMS / MMS).

A Message is created when you send or receive a message through the RELAY messaging namespace. It accumulates state-change events and resolves once the message reaches a terminal state (delivered, undelivered, or failed).

Member Function Documentation

◆ dispatchEvent()

SignalWire\Relay\Message::dispatchEvent ( Event $event)

Process an inbound event for this message.

Updates state/reason, fires any registered event listeners, and auto-resolves the message when it reaches a terminal state.

Accepts both state and message_state keys on the event payload — production RELAY emits message_state while older fixtures use state.

◆ wait()

SignalWire\Relay\Message::wait ( int $timeout = 30)

Block until the message completes or $timeout seconds elapse.

The caller is expected to feed events into dispatchEvent() from another mechanism (e.g. the client's read loop). This method simply spins until completion.

Returns
mixed The resolved result, or null on timeout.
