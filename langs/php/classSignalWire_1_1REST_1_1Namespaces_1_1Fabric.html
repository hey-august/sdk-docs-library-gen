Detailed Description

Fabric API namespace.

Mirrors Python signalwire.rest.namespaces.fabric.FabricNamespace: groups all Fabric sub-resources (subscribers, SIP endpoints, call flows, SWML scripts, conference rooms, AI agents, etc.) under a single object.

Sub-resources fall into a few buckets:

  • PUT-update CRUD: swml_scripts, relay_applications, call_flows, conference_rooms, freeswitch_connectors, subscribers, sip_endpoints, cxml_scripts, cxml_applications.
  • PATCH-update CRUD: swml_webhooks, ai_agents, sip_gateways, cxml_webhooks.
  • Special: resources (generic /api/fabric/resources), addresses (read-only /api/fabric/addresses), tokens (subscriber/guest/embed token creation).
