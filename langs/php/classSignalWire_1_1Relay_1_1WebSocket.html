Detailed Description

RELAY WebSocket transport.

This is a thin adapter over the maintained \WebSocket\Client (phrity/websocket) library. It deliberately keeps the same small public surface the rest of the SDK depends on — connect / sendText / receive / close / isConnected, plus the {

See also
self::CLOSE_FRAME} sentinel — so that {
Client} (and its test subclasses overriding createSocket()) need no changes. The previous implementation hand-rolled RFC 6455 framing on raw PHP streams; that responsibility now belongs to phrity/websocket.

Why phrity/websocket:

  • It performs a real, verified TLS handshake for wss:// URIs. A private CA (e.g. the porting-sdk test CA) is trusted by passing its cafile through the stream {
    See also
    \Phrity\Net\Context} — peer verification stays ON (no allow_self_signed, no verify_peer=false).
  • It owns frame masking/decoding, the upgrade handshake, the Sec-WebSocket-Accept check, ping/pong, and close framing.

Transport contract preserved for {

See also
Client}:
  • receive() returns the decoded text payload of the next data frame, {
self::CLOSE_FRAME} when the peer closed, or null on read timeout (socket still healthy). Ping/pong are consumed internally.
  • Outbound application messages are always text frames (JSON-RPC).

SignalWire\Relay\WebSocket::receive ( float $timeout = 5.0)

Read one complete inbound data frame, blocking up to $timeout seconds.

Returns:

  • the decoded payload string for a text/binary frame
  • {
    See also
    self::CLOSE_FRAME} for a close (or peer EOF)
  • null on read timeout (socket still healthy)

Ping frames are answered with a pong and skipped; pong frames are consumed; the next non-control frame (within the deadline) is returned.

Exceptions

RuntimeException on a fatal socket error.
