Detailed Description

Represents a section in the Prompt Object Model.

Each section contains a title, optional body text, optional bullet points, and any number of nested subsections. Mirrors Python's signalwire.pom.pom.Section byte-for-byte for render_markdown, render_xml, to_dict (and indirectly to_json / to_yaml).

Python parity: signalwire/signalwire/pom/pom.py::Section

Constructor params (params array — PHP idiom for kwargs):

  • title (?string) section title; null is permitted only on the first top-level section of a PromptObjectModel
  • body (string) paragraph text; default ''
  • bullets (?list<string>) bullet items; default []
  • numbered (?bool) null = inherit; true/false = explicit
  • numberedBullets (bool) render bullets as "1. foo" instead of "- foo"
