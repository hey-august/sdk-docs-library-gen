Detailed Description

A structured data format for composing, organizing, and rendering prompt instructions for large language models.

Mirrors Python's signalwire.pom.pom.PromptObjectModel. Provides a tree-based representation of nested sections, supporting JSON / YAML serialization and Markdown / XML rendering.

YAML support: a small bundled emitter and parser implement the subset of PyYAML's default block style needed for round-tripping POM documents. Composer-installed yaml extensions are not required.
