Detailed Description

Compatibility (Twilio-compatible LAML) API namespace.

Mounted under /api/laml/2010-04-01/Accounts/{AccountSid} and exposes the LAML-flavoured REST surface (Accounts, Calls, Messages, Faxes, Conferences, IncomingPhoneNumbers + AvailablePhoneNumbers, Applications, LamlBins, Queues, Recordings, Transcriptions, tokens) as object-style sub-resources to mirror the Python CompatNamespace class.
