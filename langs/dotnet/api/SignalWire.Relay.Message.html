Class Message

SignalWire.Relay
Assembly
SignalWire.dll

Represents a RELAY messaging message (SMS / MMS).

A Message is created when you send or receive a message through the RELAY messaging namespace. It accumulates state-change events and resolves once the message reaches a terminal state (delivered, undelivered, or failed).

Uses TaskCompletionSource for native async/await support.
