Fabric API namespace.

Groups all Fabric sub-resources (subscribers, SIP endpoints, call flows, SWML scripts, conference rooms, AI agents, etc.) under a single object. Each sub-resource is lazily initialised as a CrudResource pointing at the correct API path under /api/fabric/resources.
