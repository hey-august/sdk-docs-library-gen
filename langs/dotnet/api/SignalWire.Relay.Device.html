Remarks

Grounded in the RELAY wire schema relay-protocol/calling.connect.params.json, where each device is an object with a required type (string) and a free-form params payload. This class types the shape only: Type stays a string because the discriminant set (phone, sip, webrtc, …) is not enumerated in any schema, so an enum would risk rejecting a valid value.

The reference and the rest of this port pass devices as raw Dictionary<string, object?> (e.g. Device); this is an additive typed convenience. ToDict() yields the identical wire dictionary, so a Device can be used anywhere a hand-built device dict is accepted with no change in emitted bytes. 

var d = new Device("phone", new Dictionary<string, object?>
{
    ["to_number"] = "+15551112222",
    ["from_number"] = "+15553334444",
});
// d.ToDict() is byte-identical to the hand-written
// { ["type"] = "phone", ["params"] = { ... } }
