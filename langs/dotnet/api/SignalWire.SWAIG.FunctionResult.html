Remarks

Mirrors the Python reference execute_swml(swml_content, transfer=False): the content (a dict, or a JSON string parsed to a dict) is emitted verbatim under the SWML action key. When transfer is true, a "transfer": "true" entry is added INSIDE that SWML dict (Python does action["transfer"] = "true" on the SWML payload itself — there is no separate transfer_swml action name).
