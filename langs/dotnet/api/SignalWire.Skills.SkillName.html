Remarks

AddSkill(SkillName, Dictionary<string, object>?) (and the matching RemoveSkill / HasSkill overloads) accept this enum OR a string. The enum gives editor autocompletion and makes a typo fail at the call site — a bare string like "datetiem" only fails at runtime, on the server. Strings keep parity with the Python reference (which uses a bare str) and still allow custom / third-party skills that aren't built in.

Each member maps to its canonical snake_case wire name via ToWireName(SkillName); the enum is purely a typed alias over those strings, so wire behavior is identical to passing the string directly. 

agent.AddSkill(SkillName.Datetime);   // typed, autocompleted
agent.AddSkill("datetime");           // string still works (parity)
agent.AddSkill("my_custom_skill");    // open set: custom skills ok
