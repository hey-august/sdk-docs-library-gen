Remarks

The Python reference validates this argument explicitly (tap(... codec ...) raises ValueError unless the value is "PCMU" or "PCMA"), so it is a genuine closed set rather than a free-form string. The wire strings are upper-case ("PCMU" / "PCMA").

This is the two-value SWAIG tap codec set and is deliberately distinct from the larger RELAY connect/stream codec superset ({PCMU, PCMA, OPUS, G729, G722, VP8, H264}, optionally comma-joined): only PCMU/PCMA are valid here, so this type must not be reused for those RELAY params (which stay strings). FunctionResult.Tap(string, TapDirection, Codec, string, int, string?) accepts this enum OR a string: the enum gives editor autocompletion and turns a typo into a compile error, while the string overload preserves parity with the Python reference (which takes a bare str).

Each member maps to its canonical wire value via ToWireName(Codec); the enum is purely a typed alias over those strings, so the emitted SWML is identical to passing the string directly. 

result.Tap("rtp://1.2.3.4:5000", TapDirection.Both, Codec.Pcma);  // typed, autocompleted
result.Tap("rtp://1.2.3.4:5000", codec: "PCMA");                   // string still works (parity)
