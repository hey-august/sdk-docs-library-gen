SigningKey

Optional SignalWire Signing Key (from Dashboard → API Credentials). When set, webhook signature validation is enforced on POST /, /swaig, /post_prompt — unsigned or invalidly-signed requests get a 403. Falls back to the SIGNALWIRE_SIGNING_KEY env var if not passed. See porting-sdk/webhooks.md for the contract. (Python parity: AgentBase.init(signing_key=...).)

TrustProxyForSignature

If true, honor X-Forwarded-Proto / X-Forwarded-Host headers when reconstructing the URL for signature validation. Default false because proxy headers are spoofable; opt in only when you control the proxy chain. (Python parity: AgentBase.init(trust_proxy_for_signature=...).)
