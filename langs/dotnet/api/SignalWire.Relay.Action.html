Class Action

Base class for all RELAY call actions (play, record, collect, etc.).

An Action is the client-side handle returned when you start an asynchronous operation on a call. It accumulates events, tracks state, and resolves once the operation reaches a terminal state.

Uses TaskCompletionSource for native async/await support.

Subclasses may filter which event types can resolve this action via the standard terminal-state path. Default: any event type registered in ActionTerminalStates may resolve.

Override returns false to block resolution for a specific event type (e.g. CollectAction blocks calling.call.play so the play phase of play_and_collect doesn't resolve the collect side).
