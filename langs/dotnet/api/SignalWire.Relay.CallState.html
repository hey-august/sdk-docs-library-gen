Remarks

The RELAY calling.call.state event carries one of a known set of call-state strings (created, ringing, answered, ending, ended) — grounded in the Python reference's signalwire/relay/constants.py (CALL_STATES) and mirrored by CallStateCreated .. CallStateEnded. The reference exposes the state as a bare str; this enum is a typed alias over those strings so callers get autocompletion and a compile error on a typo, while State stays a string for parity and forward-compatibility.

This is the call vocabulary and is deliberately distinct from DialState (the dial-outcome vocabulary) and MessageState (the messaging-delivery vocabulary). The three are never conflated — they index different wire fields (call_state vs dial_state vs message_state).

Because the server emits these values and the set can grow, parse via TryParse(string?, out CallState), which returns false for an unknown value rather than throwing — the string arm on State preserves any future server value.
