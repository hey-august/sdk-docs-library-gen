Remarks

The Python reference validates these arguments explicitly (join_conference(... status_callback_method ... recording_status_callback_method ...) raises ValueError unless the value is "GET" or "POST"), so it is a genuine closed set rather than a free-form string.

Each member maps to its canonical wire value via ToWireName(CallbackMethod); the enum is purely a typed alias over those strings, so the emitted SWML is identical to passing the string directly.
