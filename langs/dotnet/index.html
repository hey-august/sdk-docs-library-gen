SignalWire .NET SDK

The official SignalWire SDK for .NET. Build voice, messaging, video, and AI-agent applications using SWML, the Relay realtime protocol, and the SignalWire REST APIs — from one library.

Native generator: DocFX — Microsoft's official documentation generator for .NET. The .NET docs themselves are built with this tool.

Install

dotnet add package SignalWire.Sdk

Quickstart — an AI agent

using SignalWire.Agents;

var agent = new AgentBase("hello", route: "/hello");
agent.PromptAddSection("Personality", body: "You are friendly.");
agent.PromptAddSection("Goal", body: "Greet the caller.");
await agent.RunAsync();

Surface

  • AI Agents — AgentBase, AgentServer, prefabs
  • REST — calls, messages, fabric resources
  • Relay — realtime WebSocket client
  • SWML / POM — programmatic SignalWire Markup Language
  • Skills — pluggable agent capabilities
