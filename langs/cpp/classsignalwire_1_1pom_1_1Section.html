Detailed Description

One section in the Prompt Object Model tree.

Mirrors Python's signalwire.pom.pom.Section. Fields are public to match the Python attribute access pattern section.body, section.bullets, section.subsections.

◆ numbered

std::optional<bool> signalwire::pom::Section::numbered

Whether this section participates in section numbering. Three-state:

  • std::nullopt — not specified (Python None); inherits.
  • true — explicitly numbered.
  • false — explicitly opted out of numbering. Numbering is "all-or-none per sibling group": if any sibling has numbered == true, every sibling gets numbered unless it explicitly opts out with false.

◆ numberedBullets

When true, bullets are rendered as a numbered list (1. 2. 3.) in markdown and as <bullet id="1"> in XML, instead of dash bullets.
