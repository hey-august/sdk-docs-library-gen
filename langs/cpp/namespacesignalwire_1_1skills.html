SkillHttpResponse signalwire::skills::http_get ( const std::string & url,
const std::map< std::string, std::string > & headers = {},
int timeout_seconds = 10 )

Issue a real HTTP GET.

Implementation uses cpp-httplib so it works against any plain-HTTP host (including loopback fixtures used by the audit_skills_dispatch.py audit). Skills that need TLS to reach production upstreams set the appropriate base-URL env var (e.g. WEB_SEARCH_BASE_URL) — production deployments point at TLS proxies or a dev-side rewriter; the SDK keeps its transport stack OpenSSL-3 independent until the wider port adopts it.
