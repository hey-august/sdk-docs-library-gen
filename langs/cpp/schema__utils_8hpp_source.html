1// schema_utils.hpp — C++ port of signalwire.utils.schema_utils.SchemaUtils.
2//
3// Loads the SWML JSON Schema, extracts verb metadata, and validates
4// either a single verb config or a complete SWML document. Validation
5// is lightweight (verb existence + required-property check) by default;
6// full JSON Schema validation can be wired in via
7// nlohmann/json-schema-validator by extending init_full_validator.
8//
9// Construction rules mirror Python:
10//
11// - Pass schema_path = "" to use the embedded schema.json.
12// - schema_validation = false disables validation
13// (validate_verb returns (true, []) for every call).
14// - The env var SWML_SKIP_SCHEMA_VALIDATION=1/true/yes also disables
15// validation regardless of the constructor argument.
