163 // [[nodiscard]]: the return value is the whole point of a wait — it tells
164 // you whether the call actually reached the terminal state vs. timed out.
165 // Silently dropping it (then acting as if the call ended) is a bug.
166 [[nodiscard]] bool wait_for_ended(int timeout_ms = 0);
167
168 // Typed state-wait convenience (mirror Python's wait_for_answered/
169 // wait_for_ringing/wait_for_ending). Block until the call reaches the
170 // named state, returning immediately if it is already at or past that
171 // state in the lifecycle order created<ringing<answered<ending<ended.
172 // Return true on reaching the state, false on timeout. timeout_ms<=0
173 // waits indefinitely. (Python returns the state RelayEvent; the C++
174 // idiom returns bool to match wait_for_ended — see
175 // PORT_SIGNATURE_OMISSIONS.md cpp_wait_returns_bool.)
176 // [[nodiscard]] for the same reason as wait_for_ended: ignoring the
177 // reached-vs-timed-out result is always a bug.
178 [[nodiscard]] bool wait_for_answered(int timeout_ms = 0);
179 [[nodiscard]] bool wait_for_ringing(int timeout_ms = 0);
180 [[nodiscard]] bool wait_for_ending(int timeout_ms = 0);
