void signalwire::skills::SkillRegistry::add_skill_directory ( const std::string & path)
inline

Add a directory to search for skills.

Mirrors Python's signalwire.skills.registry.SkillRegistry.add_skill_directory: validate that the path exists and is a directory, then append it (de-duplicated) to external_paths_. Throws std::invalid_argument (the C++ analog of Python's ValueError) for invalid input — the path doesn't exist or isn't a directory.
