◆ record_format_values()

std::vector< std::string > signalwire::swaig::record_format_values ( )
inlinenodiscard

Helper: the closed-set values for the Tier-1 SWAIG enums, as the exact wire strings, ready to hand to enum_of(...). These reuse the SAME *_value() normalization point as the typed FunctionResult overloads, so a schema built with record_format_values() lists precisely the strings FunctionResult::record_call accepts — one source of truth for each set.
